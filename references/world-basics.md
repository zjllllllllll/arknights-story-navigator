# 基础世界观：只帮助理解与定位

这是词义导航，不是具体问题的证据。来源优先从主线开篇、罗德岛相关正文、人物档案和所问国家的活动原文回查；深层起源、历史真相与人物动机不在这里预填。

- **泰拉**：故事的主要舞台。天灾影响生活与城市发展，移动城市是重要的应对方式；并非所有聚落都移动。
- **源石**：广泛参与能源、工业和源石技艺，同时与天灾及矿石病密切相关。这里只描述社会通常认识，不替代后续剧情揭示的起源与机制。
- **矿石病与感染者**：接触源石等情形涉及感染风险；疾病、社会排斥和感染者处境是重要冲突。具体传播条件、病程、死亡过程应查原文，不从现实疾病类推。
- **源石技艺**：泰拉的重要能力与技术体系；不同人的能力及使用条件不同。不能把所有特殊能力都归为源石技艺。
- **泰拉人与族群**：族群、国籍、组织归属是不同维度；动物特征不意味着可以直接套用现实动物习性。称号、代号和种族名称也不能互换。
- **罗德岛**：与医疗、矿石病研究及感染者问题紧密相关。干员身份不能自动推出国籍或血缘。
- **巴别塔、整合运动**：涉及不同时期的人物和政治行动，成员、目标及组织状态会变化；按所问时间查证。
- **国家与地区**：炎、乌萨斯、维多利亚、哥伦比亚、莱塔尼亚、卡西米尔、拉特兰、伊比利亚、谢拉格、叙拉古、萨尔贡、卡兹戴尔、阿戈尔等是可能的地域入口，不据一个国家标签推定人物全部立场。
- **时间与叙事**：作品发布顺序、泰拉历事件顺序和玩家阅读进度不是一回事。主线、活动、档案、肉鸽均可能包含回忆、视角限制和后续揭示。

遇到陌生名词，先用名字定位相关作品或条目，再读原文；不必先补完所有世界观。
